## 📌 Project Overview

A comprehensive healthcare portal connecting patients with clinical specialists, electronic prescription records, laboratory results, and health tracking dashboards.

---

## 🚀 Key Features

- **Electronic Health Records:** Unified timeline of clinical visits, lab reports, and vitals.
- **Prescription Refills:** One-click prescription renewal requests sent directly to pharmacies.

---

## 🚦 Getting Started

### 1. Clone the Repository
`ash
git clone https://github.com/chilkotiKartik/healthverse-platform.git
cd healthverse-platform
`

### 2. Install Dependencies
`ash
npm install
`

### 3. Run Development Server
`ash
npm run dev
`

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
